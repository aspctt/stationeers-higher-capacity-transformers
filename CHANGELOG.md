# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

## [1.0.1] - 2026-10-22

### Added

- A warning in the log when a transformer can't be found, for example after a game update renames it

### Changed

- Medium Transformer setting steps raised to 500 W, or 50 W for small steps, so dialing it to the maximum takes 200 clicks instead of 1,000
- Log messages go through BepInEx under the name Higher Capacity Transformers

## [1.0.0] - 2026-07-13

First release.

### Added

- Medium Transformer output raised from 25,000 W to 100,000 W, on both the standard and reversed variants
- Large Transformer output raised from 50,000 W to 500,000 W, with its setting steps scaled up to match
